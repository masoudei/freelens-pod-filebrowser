# awesome-kubernetes Submission Guide

**Repo:** https://github.com/ramitsurana/awesome-kubernetes

## Steps

1. **Fork** the awesome-kubernetes repo
2. **Edit** `README.md` — add entry under appropriate section
3. **Submit PR**

## Suggested Entry

Add under ** Tools and Libraries → IDE & Editors & Plugins** or create a **Freelens Extensions** subsection:

```markdown
### Freelens Extensions

* [freelens-pod-filebrowser](https://github.com/masoudei/freelens-pod-filebrowser) - Browse, view, edit, upload, and delete files inside Kubernetes pod containers directly from Freelens.
```

## PR Description

```
Title: Add freelens-pod-filebrowser (pod file browser for Freelens)

Adds a Freelens extension for browsing Kubernetes pod filesystems:
- Browse directories, edit files in Monaco editor, upload/download
- Uses kubectl exec through Freelens proxy (no sidecars)
- MIT licensed
```

## Follow-up

After PR is merged, the link from awesome-kubernetes (15k+ stars) will drive continuous referral traffic.
